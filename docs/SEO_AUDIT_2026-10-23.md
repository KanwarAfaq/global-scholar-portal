# SEO / AEO / GEO on-page audit — 2026-10-23

**Scope and limits.** The live site (`scholarportal.site`) was not reachable from the audit environment, so this audit is based on the code and on the production build (631 prerendered snapshots) with a mocked Supabase backend. Real search-engine, Search Console, field-performance and live-data behaviour were not tested.

## Fixed in this change

| Area | Finding | Fix |
|---|---|---|
| Structured data | Home page lost WebSite/Organization schema (all JSON-LD stripped in prerender) | Second `@graph` per snapshot: Organization, WebSite + SearchAction, BreadcrumbList |
| Structured data | Article schema lacked image, language, access flag, raster logo | Added `image`, `inLanguage`, `isAccessibleForFree`, PNG publisher logo |
| Sitelinks search | SearchAction advertised `/?q=` but the app ignored it | Dashboard now reads and prefills `?q=` |
| Social | Only 100 of 625 articles had `og:image`; twitter title/description missing | Default 1200x630 OG image, full OG + Twitter tags on every page (631/631) |
| Snippets | 603 meta descriptions over 160 chars | Clamped to 158 chars (0 remain over 160) |
| Titles | Brand suffix pushed titles over limit | Suffix only added if title stays ≤65 chars |
| Crawlable content | No breadcrumbs or byline in snapshots | Breadcrumb nav and byline with `<time>` |
| Pagination SEO | `?page=N` shared one title/canonical | Self-canonical and "– Page N" title for `/` and `/blog` |
| AEO | FAQ was plain blocks | `<details>/<summary><h3>` accordions matching FAQPage schema |
| GEO | Thin llms.txt, no AI-crawler rules | Richer `llms.txt` (30 latest entries generated at build), explicit Allow for OAI-SearchBot, ChatGPT-User, Claude-SearchBot, Claude-User, PerplexityBot, Perplexity-User |

## Needs a human / editorial decision

1. **16 duplicate-title groups** (build now warns). Examples: `/blog/applying-to-grad-school-the-ultimate-guide-*`, and repeated Eiffel, EPFL, KAIST, MBZUAI, Gates Cambridge and DAAD opportunity pages. Merge, differentiate or canonicalise; not changed automatically.
2. **303 titles are still over 65 characters.** Editorial; fix in the content generator.
3. **Search Console:** verify the sitemap, coverage and the `X-Robots-Tag: noindex` private routes (robots.txt intentionally has no Disallow so the header is seen).
4. **Performance:** collect CrUX/field data; the ResumeBuilder chunk is ~1.29 MB and should be lazy-loaded or split.
5. Re-run this audit against the live site once it is reachable.
